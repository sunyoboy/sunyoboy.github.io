# 知行合一 · 知识汇总助手

## 何时使用

当用户要求生成周报、整理笔记、沉淀规则、汇总复盘内容时使用。

触发词：周报、汇总本周、整理笔记、沉淀、知识总结、knowledge-summary

---

## 规则来源（执行前必读）

规则总纲：`docs/report-note-sop.md` —— 日报 D1–D7 / 周报 W1–W6 / 笔记 N1–N6。
本 Skill 是该总纲的执行入口，与总纲冲突时以总纲为准。

---

## 执行流程

### 模式 A：周报生成（默认）

1. **确定范围**：定位本周 `review/YYYY/MM/` 下的 5 篇日复盘（周一至周五）
2. **逐篇提取**（映射表 · 只引用不重算）：
   | 周报字段 | 从日报哪里取 |
   |---|---|
   | 本周盈亏 | 每日"持仓盈亏"→ 末日累计 − 上周五累计 |
   | 胜率 / 做T次数 | 每日"做了什么"逐日点数 |
   | 最大教训 | 每日"学到了什么"挑影响最大 1–2 条 |
   | 下周计划 | 每日"明日计划"合并去重 → 砍到 ≤3 件 |
3. **按 P→D→C→A 输出**（骨架见 `growth/个人周报模板.md`），**C 部分（偏差归因 + 如果重来）必填，不允许跳过**
4. **数字口径矛盾** → 回日报订正，不在周报里"修正"
5. **落盘**：交易周报 → `review/YYYY/MM/YYYY-WNN.md`；个人周报 → growth/

### 模式 B：笔记整理

1. **收集候选**：从指定范围的日报"学到了什么"+ 周报 C 部分收集候选条目
2. **过沉淀判据 N1**（三选一，否则明确说"留在日报，不沉淀"）：
   - 复现：同类教训出现 ≥2 次（引用具体日期）
   - 可迁移：跨场景成立，不绑定单一标的/日期
   - 可执行：能写成"如果 <条件>，就 <动作>"
3. **查路由表分流**（总纲第四节）：纪律教训→position-discipline 等对应章节；新方法论→docs/ 新专题；认知偏差→mindset；待验证→questions/；重复手工→scripts/
4. **三段式格式**：规则语句 + 来源链接 + 验证记录（+ 反例）。原文不删，只放链接
5. **联动提示**：输出末尾列出需同步更新的 catalog.md / config.mjs 条目

### 模式 C：主题汇总

按关键词扫描 `review/` + `questions/` + `growth/`，金字塔原理输出：定义 → 分类 → 简明总结。
