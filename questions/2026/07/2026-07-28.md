## 产检建档与生产医院分析

### 建档和产检必须在一个医院吗？

**不一定。但强烈建议在计划生产的医院建档。**

```
建档 = 建立孕期档案，医院开始系统管理你的孕期全程
       ↓
建档医院 → 通常 = 生产医院
       ↓
为什么？→ 生产医院需要完整的孕期记录
         → 从建档到生产的每一次产检，同一个系统里有全量数据
         → 接产医生了解你的全部高危因素
```

**可以做的事**：
- 在郑大一附院建档，大部分产检在郑大一附院做
- 常规检查（血压/体重/尿检）可以在鄢陵当地医院做，结果带到郑大一附院
- 关键节点（NT、大排畸、糖耐量）必须在建档医院做

**不建议做的事**：
- 在鄢陵建档、在郑大一附院生产 → 郑大一附院可能不接收「外院建档」的产妇
- 在哪都不建档 → 孕晚期没有医院愿意接收

---

### 可以在郑大一附院看病、在鄢陵生产吗？

**技术上可以。但对你的情况，不建议。**

| | 郑大一附院 | 鄢陵县医院 |
|------|:--:|:--:|
| 等级 | 三甲（最高） | 二甲或以下 |
| 高危妊娠处理能力 | ✅ 全省最强 | ⚠️ 有限 |
| NICU（新生儿重症） | ✅ 有 | ❓ 不确定 |
| 产科急救能力 | ✅ 多科室协同 | ⚠️ 可能需要转院 |
| 距离 | 郑州·距鄢陵约 2-3 小时 | 家门口 |

**你的情况是「三高危」**：

```
39岁高龄 + 复发性流产史 + 易栓症
    ↓
不是普通妊娠，是高风险妊娠
    ↓
生产时需要：产科+血液科+新生儿科 多科室备勤
    ↓
县医院不具备这个条件
```

> ⚠️ **易栓症产妇生产时需要全程抗凝管理**——肝素什么时候停、什么时候恢复、产后如何抗凝。这不是县医院能独立处理的。郑大一附院有血液科+产科联合管理的能力，这是选择生产医院的第一标准。
