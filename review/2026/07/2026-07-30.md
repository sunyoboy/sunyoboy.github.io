### 🔍 大跌原因拆解

#### 表层：FOMC 失望

```
市场预期：鸽派（降息信号 + 一致通过）
实际结果：中性偏鹰（按兵不动 + 9:3分裂 + 3人主张加息）

→ 预期差 = 失望 = 抛售
→ 但这只解释了早盘 -0.26% → 解释不了上午加速到 -1.15%
```

#### 中层：FOMC 的二次传导

```
FOMC 内部分裂（9:3）→ 政策路径不可预测
    ↓
9月降息概率下降 → 美债收益率维持高位
    ↓
高估值成长股（创业板/科创）杀估值
    ↓
中小盘 ETF（中证500）被连带抛售
    ↓
你的中证500 -3.47% ← 这是传导链的终端
```

#### 深层：结构性踩踏

```
7/27 追涨的人       → 7/28 被套（-7.35%）
7/29 反弹抄底的人   → 7/30 被埋（-5.89%）
融资盘/杠杆资金     → 触发强制平仓
程序化止损盘        → 越跌越卖
    ↓
这就是「加速下跌」的来源——
不是有人恶意做空，是前两天的抄底盘在割肉。
```

#### 为什么防御还在涨？

```
食品饮料 +2.51%、银行 +1.83%
    ↑
  同一笔钱从科技/成长撤出 → 涌入消费/金融避险
  这不是「看好银行」—— 这是「没地方去了」
```
