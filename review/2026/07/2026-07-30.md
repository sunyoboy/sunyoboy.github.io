### 大跌原因·六层拆解

#### 第一层 · 预期差：FOMC 不如预期

```
市场预期：鸽派（降息信号 + 一致通过）
实际结果：中性偏鹰（按兵不动 + 9:3分裂 + 3人主张加息）
    ↓
预期差 → 失望性抛售（早盘 -0.26%）
但这一层只解释前 30 分钟，解释不了后续加速
```

#### 第二层 · 二次传导：从美联储到你的持仓

```
FOMC 内部分裂（9:3）→ 政策路径不可预测
    ↓
9月加息概率仍高达 59-63% → 美债长端利率维持高位（10Y 4.67%）
    ↓
全球成长股估值重定价（DCF模型：分母不动=估值不涨）
    ↓
创业板/科创50首当其冲（高估值 + 高外资占比 + 高利率敏感）
    ↓
中证500被连带（成分股里有科技+成长，虽不纯但被一起卖）
    ↓
你的中证500 -2.86% ← 传导链终端
```

#### 第三层 · 踩踏：抄底盘割肉→加速下跌

```
7/27 追涨的人       → 7/28 被套（-7.35%）→ 扛着
7/29 抄底的人       → 7/30 被埋（-5.89%）→ 扛不住了 → 割
融资盘              → 连续下跌触发券商强平 → 被迫卖
程序化止损盘        → 跌破关键位（科创破1650→1588）→ 自动卖出
    ↓
每一波割肉都把价格往下砸一档，砸出来的低价触发下一波止损
    ↓
这就是上午从 -0.26% 加速到 -1.15% 的力学原理——
不是有人恶意做空，是杠杆在连环爆破
```

#### 第四层 · 流动性枯竭：缩量的代价

```
7月成交额：3.7万亿（7/1）→ 1.87万亿（7/28）→ 更低（7/30）
    ↓
缩量 = 流动性下降 = 每一笔卖出的冲击变大
    ↓
同样卖 1000 万：
  3.7万亿市场 → 价格滑 0.01%
  1.8万亿市场 → 价格滑 0.05%
    ↓
流动性越差 → 卖盘对价格的打压越狠 → 越跌越没人接 → 越没人接越跌
```

#### 第五层 · 行为金融：习得性无助

```
这是「狼来了」的极端版本——

7/27 抄底 → 7/28 被埋
7/29 抄底 → 7/30 被埋
    ↓
每次抄底都被惩罚 → 投资者学会了「不能抄底」
    ↓
买盘消失 → 市场上只剩下卖盘
    ↓
没有买盘的下跌 = 自由落体
```

> 「市场底部从来不是卖盘耗尽的时候，是买盘开始敢买的时候。」现在的问题是——抄底的人连续两天被惩罚，第三天没人敢抄了。

#### 第六层 · 政策真空：没有国内对冲

```
外部：FOMC分裂 → 全球风险偏好下行 + EM资本外流
内部：7月底 → 政策空窗期（政治局会议已过、秋季政策尚未出台）
    ↓
没有国内利好可以对冲外部利空
    ↓
A股完全暴露在外部冲击之下，没有「护盘预期」
    ↓
如果有降准/降息/产业政策 → 可以止血
现在什么都没有 → 血一直流
```

### 盘面特征

- **FOMC 落地 ≠ 利空出尽**：利率不变是预期内，但 9:3 分裂超出预期。市场现在担心「联储内部打架→政策路径不可预测」。美债长端利率上行（10Y 4.67%）才是真正的杀器——它从分母端压缩了所有成长股的估值天花板。
- **大票稳、小票崩**：上证50 +0.39% vs 科创50 -5.38%。午后国家队拉银行+沪深300护指数，但中小创不在护盘范围内，全天躺平。
- **周期/资源逆势走强**：天山 +0.69%、紫金 +1.71%、黄金 -0.28%。资源股在 FOMC 不确定性中成了避风港——通胀预期支撑大宗商品。
- **你的减仓被验证** ✅：FOMC 前将仓位降至安全水位，逆回购锁住现金。如果没减仓，今天科创 -6.02%+中证500 -2.71% 会再咬一口。
- **30年国债 ETF +0.24%**：避险资金涌入，债券成为今天除银行/食品饮料外少数正收益资产。
