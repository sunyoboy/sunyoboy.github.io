# 📈 全球股市行情平台

> 单文件实时行情看板 · 覆盖 A股 / 港股 / 美股 / 指数 / 板块 · 内置回测与仓位计算器

**[→ 在线体验](/charts/global-markets.html)**（新标签页打开）

---

## 它是什么

一个**单文件 HTML**（零依赖、零后端）的行情看板，打开即用。所有数据通过浏览器实时拉取，
涵盖 A股、港股、美股、指数与板块排行，并附带策略回测与仓位/风险计算器。

## 核心功能

| 模块 | 说明 |
|------|------|
| 🌍 全球指数 | A股 / 港股 / 美股主要指数实时行情，涨跌一目了然 |
| 📊 板块排行 | 申万行业 / 概念板块涨幅榜（东财接口） |
| 💹 个股行情 | 自选标的实时报价、涨跌幅、成交量 |
| 🧪 策略回测 | 均线策略回测（模板/参数/止损模式可配），输出收益、回撤等指标 |
| 🧮 仓位计算器 | 按账户资金 / 风险比例 / 入场价 / 止损价自动建议仓位 |

## 技术实现

| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | 原生 HTML + CSS + JS（Canvas） | 单文件，无构建、无依赖 |
| 数据源 | 腾讯财经（`qt.gtimg.cn`）· 新浪财经 · 东方财富（`push2`） | 浏览器 `fetch` 直连，CORS 开放 |
| 部署 | 静态托管（VitePress `public/`） | 随站点一起发布，无需服务器 |

## 设计思路

- **单文件优先**：投资类的工具，最重要的是「打开就能用」。不做登录、不搭后端，一个文件解决全部问题。
- **数据源冗余**：腾讯 / 新浪 / 东财三个接口互备，某一路挂了不至于整块白屏。
- **面向真实决策**：不止看行情——回测与仓位计算器都服务于「今天该不该买、买多少」这个真实问题。
