# 情绪拆解

## 何时使用

- 用户描述一件**具体**的事并伴随情绪代价：演讲、汇报、面试、体检报告、冲突、亏损、等待结果
- 用户自己用了「内耗」「焦虑」「怕」「睡不着」「一直想」这类词

不适用：纯概念提问（"什么是焦虑"）；已出现需要专业干预的信号（见「边界」）。

## 核心判断

情绪不会自动消失，再小的事也一样。让它消散的不是安慰，而是看清楚它——写下来，追问最坏情况，接受，再改善。

> 恐惧就是个欺软怕硬的货色，你躲避它，它就张牙舞爪；你正视它，它就原形毕露。

出处：卡耐基《人性的弱点》的三步法 + 《认知觉醒》的「正视它、看清它、拆解它、化解它」，两条路径在做同一件事。

## 第 0 步：先写下来

《认知觉醒》「改变人生的 9 件小事」其一：**写下任何干扰你情绪的事**。

不写下来，情绪就在后台空转——它会伪装成「我在思考」，其实只是在重播同一段画面。落笔的瞬间它才从情绪变成可拆的对象。写三样东西：**触发事件**（什么时候、谁、发生了什么）、**身体反应**（胸口紧、睡不着、没胃口）、**脑子里循环的那句话**。写的时候只记录，不分析、不评价自己该不该有这种情绪。

写完再进三步法。

## 三步法（顺序不可跳）

1. **最坏的情况是什么？** —— 必须具体到可描述的场景，而不是「我会很惨」。锚定时间、场合、别人会看到什么。
2. **能不能接受它？** —— 接受不是认命，是把最坏结果从「不可想象」降级为「可承受」。说清真实代价是什么、不是什么。
3. **怎么改善最坏的情况？** —— 只有这一步才产出任务，前两步是把它从情绪里挪到桌面上。

## 任务分解

第 3 步的答案必须落成任务，否则只是自我安慰。每条任务写清：**动作 · 什么时候做 · 完成标准**。

- 只拆**自己可控**的部分（准备、练习、话术、备份方案、退路），不拆依赖他人或运气的结果
- 粒度控制在一次能做完，避免「多准备一点」这类无法验收的表述
- 拆完当天不再回看情绪本身，情绪留给「接受它」那一步

## 输出格式

```text
**触发事件**：<什么时候、谁、发生了什么 · 身体反应 · 循环的那句话>
**最坏情况**：<具体场景>
**接受它**：<最坏结果的真实代价是什么、不是什么>
**改善任务**：
- [ ] <动作> · <时间> · <完成标准>
**不可控部分**：<剩下的交给时间，不再反复推演>
```

## 完整示例（上台演讲焦虑）

**最坏情况**：紧张到声音发抖；专家提问回答不上来。
**接受它**：声音发抖，大不了别人觉得我经验不足，但不会因此嘲笑我；答不上来就大方承认这块了解不够，谢谢提醒、回去落实——这不是辩论赛，不需要赢。
**改善任务**：
- [ ] 通读背景资料并列出可能被问的 5 个问题 · 演讲前一晚 · 每问能说出 3 句回答
- [ ] 完整试讲一遍并录音 · 演讲前一天 · 听完能定位卡壳段落
- [ ] 练习发抖时的应对：深呼吸一次再接着说 · 试讲时 · 能在中断后 5 秒内接上
**不可控部分**：专家的具体问题、现场氛围——准备到此为止，不再推演。

事后验证：做好了最坏打算，反而没有抖到失声，专家的问题也没想象中难。真正消耗人的从来不是那件事，而是没有出口的预演。

## 边界

- 不替用户决定「做不做这件事」，只拆他的最坏情况和任务；选择权始终在用户手里
- 用户出现持续两周以上的情绪低落、长期失眠、自伤或轻生念头 → 明确建议寻求专业心理帮助，不用三步法替代诊疗
- 这类内容是隐私：不主动复述、不写进仓库文档、不外发，只在当下对话里使用
