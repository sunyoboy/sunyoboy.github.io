# 结构性牛市作战手册：李迅雷框架 + 可执行清单

> **一句话**：存量经济下**没有全面牛市，只有结构性牛市**；它的本质就是 **K 型分化的牛市**——一部分资产走牛，另一部分持续走弱甚至阴跌。它不是普涨，是"强者的牛市"。
>
> **最大陷阱**：误以为这只是轮动，于是弃强择弱，等冷门板块补涨。

## 零、前提对齐

李迅雷的核心判断，必须先站在这三条上，后面的所有动作才成立：

1. **存量经济**：增量做大的时代结束，蛋糕不再自动变大
2. **只有结构性牛市**：指数层面难有大牛市，机会集中在少数赛道
3. **结构性牛市 = K 型分化的牛市**：上沿走牛，下沿阴跌，中间被抽空

> 对应的宏观底层：**投资拉动走不通**（15 年 PPI 累计涨幅≈零）→ 实体给不出普遍回报 → 资金只能在少数"确定性资产"里抱团。
> 详见 [K 型分化与三类问题诊断](k-shaped-divergence)。

## 一、结构性牛市的五个特征

1. **主线清晰、持续时间长，但扩散性弱**：资金集中在少数赛道、少数龙头，绝大多数标的跑不赢指数。
2. **轮动是次要的，集中度提升是主线**：不要把短期轮动当成新主线。
3. **低估值不等于安全**：大量标的长期处于"价值陷阱"，**低估可以一直低估**。
4. **驱动不是流动性大水漫灌**，而是**业绩确定性、现金流稀缺、长期需求慢变量**（人口、产业升级）。
5. **拐点很难预判**：结构性行情一旦形成，趋势延续性强，**博弈反转的性价比很低**。

> **一句话区分**：
> 增量牛市是"**水涨船高**"；结构性牛市是"**水往少数洼地／确定性资产里流**"。

## 二、五条应对原则

李迅雷的思路可以浓缩为一句：**追随趋势，不赌扩散、不赌补涨。**

### ✅ 1. 放弃"等补涨"思维（最重要的一条）

大多数人的亏损来源：看着主线涨得多，觉得贵，跑去埋伏低位冷门，等着轮动补涨。

**存量环境蛋糕有限，主线走强本身就意味着其他板块的资金被虹吸。**

- 不是不能做轮动，而是**不要把"押注补涨"当作主策略**；轮动属于次级机会、难度更高。
- **主线贵，是"确定性溢价"**。在资产荒、优质标的稀缺的环境下，溢价可以长期存在。

### ✅ 2. 仓位分层

| 层次 | 比例 | 做什么 | 纪律 |
|---|:--:|---|---|
| **主线底仓** | 大部分资金 | 已形成趋势、现金流扎实、份额向头部集中的主线龙头／宽基／行业 ETF | **顺势持有，不频繁高抛低吸猜拐点**；赚业绩与确定性溢价的钱 |
| **博弈仓** | ≤20% | 阶段性轮动、政策催化 | **严格止损、不长期拿**；明确知道这是事件驱动，不是长期趋势 |
| **现金／固收缓冲** | 保留 | 应对波动、主线短期回调 | 避免被迫割在调整阶段；**不要满仓押单一结构主线** |

### ✅ 3. 选品标准：抓"结构性稀缺"

结构性牛市涨的，本质是**供给稀缺、长期需求稳定**的资产：

| 维度 | 要什么 | 避开什么 |
|---|---|---|
| **行业格局** | 寡头化、头部份额持续提升、竞争格局清晰、内卷收敛 | 产能过剩、持续内卷 |
| **财务** | 稳定自由现金流、ROE 可持续、不靠持续融资续命 | 现金流薄弱、依赖补贴 |
| **需求端** | 受人口、产业升级等**慢变量**支撑 | 一次性政策刺激 |
| **地位** | 行业头部 | 尾部小企业 |

### ✅ 4. 数据跟踪：抓慢变量，过滤高频噪音

| 重点跟踪 | 弱化 |
|---|---|
| 行业集中度变化 | 单日涨跌 |
| 龙头盈利占比 | 短期情绪 |
| 居民收入结构 | 零散利好传闻 |
| 人口流向 | 分时图 |
| 资本开支 | 小道消息 |

**只要底层逻辑没被基本面证伪，趋势就不容易结束**——不要因为短期调整就判定主线结束。

### ✅ 5. 估值的正确用法：估值是参考，不是反转信号

存量环境下估值体系会**重构**：

```
高估值 + 持续高增长 + 格局持续优化  →  溢价可以维持
低估值 + 份额持续丢失 + 需求萎缩    →  价值陷阱
```

**判断优先级：产业格局与现金流 > PE/PB。**

## 三、两套实操方案

### 方案 A（省心版，适合大多数人）

- 以**宽基指数基金 + 主线赛道龙头基金**为主，均衡配置
- **不频繁换赛道**，降低交易频率，不追逐热点轮动
- **不加杠杆**

### 方案 B（能力更强、有研究时间）

- **底仓拿主线龙头**，小仓位做阶段性机会
- 设置明确规则：**主线逻辑破坏才减仓，而不是单纯因为"涨多了"就卖**

> ⚠️ **方案 B 的关键不是"更激进"，而是"减仓依据不同"**——从"看价格"切换到"看逻辑"。这是最难的一步，也是本节唯一真正的增量。

## 四、四个大坑

| # | 坑 | 为什么是坑 |
|:--:|---|---|
| **1** | 主线涨多了，主观认定泡沫，重仓布局冷门等补涨 | 存量环境下冷门可能永远不补涨，主线继续走 |
| **2** | 把短期反弹当成新主线，不断追新热点 | 来回打脸，手续费与滑点吃掉所有收益 |
| **3** | 满仓单一主线，不加缓冲 | 主线深度回调时扛不住，被迫在低点卖 |
| **4** | 用周期思维看，"涨久必跌、跌久必涨" | 忽略存量分化的**长期化**——分化不会均值回归 |

## 五、离场／减仓信号

**不是猜高点，而是看主线底层逻辑是否被证伪。**

```
□ 1. 行业竞争格局恶化，龙头份额不再提升
□ 2. 长期需求逻辑发生根本性变化
□ 3. 盈利持续不及预期，现金流恶化
□ 4. 流动性环境出现系统性收紧（不是短期微调）
```

**只要核心逻辑还在，结构性行情就可能延续。**

## 六、【补充】如何判定"现在是不是结构性牛市"

上面是"怎么应对"，但前提是**先确认状态**。否则会把反弹当牛市，或把牛市当反弹。

### 三个判据（每天都可查）

| 判据 | 算法 | 结构性牛市 | 全面牛市 |
|---|---|---|---|
| **① 指数 vs 等权** | 市值加权指数涨幅 − 等权指数涨幅 | 明显为正（>2pp） | 接近 0 |
| **② 领涨集中度** | 前 3 板块涨幅贡献 ÷ 全市场涨幅 | >70% | <50% |
| **③ 上涨家数占比** | 上涨家数 ÷ 全市场 | <60%（涨停多但普涨少） | >80% |

**判定规则：三判据中 ≥2 条成立 → 结构性状态；3 条全成立 → 强结构性。**

### 2026-11-04 的实盘样本（可直接套用）

| 指数／标的 | 涨幅 |
|---|--:|
| 科创50 | **+9.92%** |
| 创业板指 | +6.40% |
| 中证500 | +4.66% |
| 沪深300 | +2.31% |
| 上证 | +2.16% |
| **格力电器** | **-0.59%** |

**同一天，科创50 与格力差 10.5 个百分点。**
→ 判据①成立（科创/创业板远超上证）· 判据③成立（权重股格力下跌）
→ **这是一个标准的结构性牛市单日样本，不是普涨。**

### 但还要区分"启动"还是"反弹"

| 指数 | 10/20 | 11/3 昨收 | 两周变化 | 11/4 单日 |
|---|--:|--:|--:|--:|
| 科创50 | 1358.65 | 1151.28 | **-15.3%** | +9.92% |
| 创业板指 | 2739.20 | 2391.65 | **-12.7%** | +6.40% |
| 上证 | 3735.37 | 3608.10 | -3.4% | +2.16% |

**两周跌 15%，单日弹 10% —— 位置仍在下跌通道内。**
**确认"启动"的最低条件：连续 2–3 日不破当日低点 + 成交额不萎缩。**

## 七、【补充】两套操作系统的切换

这是本人系统最缺的一环：**只有一套防守型规则，没有进攻型规则。**

| 维度 | 破位市（防守） | 结构性牛市（进攻） |
|---|---|---|
| 总仓位 | 越轻越好（权益 ≤40%） | 核心+卫星（权益 60–65%） |
| 仓位重心 | 现金 | **结构**（钱放在哪条腿 > 放多少） |
| 止损 | 慢（等反弹到 MA5） | **快**（-8% 或破 MA20 即走） |
| 加仓 | 禁止 | **可以，但只加到赢家身上** |
| 减仓依据 | 价格（偏离度/止损线） | **逻辑**（卡片第五节四条） |
| 时间止损 | 适用 | **只对博弈仓用**；主线底仓不设时间止损 |
| 目标 | 保命 | 让利润奔跑 |
| 心态 | 少亏就是赢 | **不参与的成本 < 参与错的成本** |

### 关键冲突裁决：现有 MA5 规范 vs "不猜拐点"

| 现有纪律 | 与本文框架的冲突 | **裁决** |
|---|---|---|
| 反弹至 MA5 减仓（[MA5 决策矩阵](ma5-deviation-discipline)） | 直接冲突：卡片要求"顺势持有，不频繁高抛低吸猜拐点" | **MA5 减仓只在"防守状态"生效**；进入"进攻状态"后切换为"逻辑破坏才减" |
| 现金 ≥50% | 结构性牛市里 35% 效率更高 | **按状态切换**：防守 50% ／ 结构性 35% ／ 全面牛 20%（判据见第六节） |
| 单品种 ≤10% | 主线底仓需要"重" | 用**"主线组"**替代"单只"：一组 ≤3 只、合计 ≤30%，单只仍 ≤10% |
| 时间止损 20 日 | 趋势延续性强，20 日可能刚启动 | 时间止损**仅适用博弈仓**；主线底仓改为"逻辑止损" |
| 5 只 × 10% = 权益上限 50% | 结构性状态下需要集中 | 结构性状态允许：**核心 3 只 ×10% + 卫星 2 只 ×7% + 现金 35%** |

> ⚠️ **切换开关必须客观**：三判据 ≥2 条成立 **且** 组合相对强度（持仓 vs 沪深300 近 20 日）为正 → 才允许切进攻。
> 只凭"今天大涨"就切换 = 把规则改成情绪。

## 八、【补充】落到本人账户

> ⚠️ 下列数字基线为 **2026-10-20 收盘持仓**，按 11/4 收盘价重估；实际持仓如有变动需重算。

### 8.1 三层仓位映射

| 层次 | 现有标的 | 占比 | 判断 |
|---|---|--:|---|
| **核心（确定性）** | 黄金ETF 2.0% · 30年国债（已清） · 逆回购 | **2.0%** | 🔴 太薄——哑铃的"确定端"几乎为零 |
| **主线（结构性）** | 有色/稀土/钨 15.7% · 中韩半导体 0.7% · 创新药 0.6% | **17.0%** | 🟡 方向对，但缺止损纪律 |
| **中位数（低效）** | 沪深300 19.6% · 中证500 20.4% · 创业板 3.8% · 科创 3.0% | **46.7%** | 🔴 **用最大仓位赚最平庸的收益** |

### 8.2 11-04 当日的实际位置（估算）

```
权益 ≈ 187,097（单日 +4.1%，约 +7,370）
总资产 ≈ 264,932
账户回报 ≈ -8.9%
（10/20 为 -7.2% → 两周内恶化至约 -11.4% → 11/4 修复到 -8.9%）
```

**今天这个 +10% 的科创50，对 -8.9% 的账户不是"牛市来了"，是"回血"。**
判断该做什么，取决于一个前置问题：**10/20 那份减仓清单执行了几笔？**

| 若已执行（权益约 60%） | 若未执行（权益仍 71%） |
|---|---|
| 反弹是"持仓修复"，可留卫星腿并补挂止损 | **反弹是减仓窗口**，按原计划降宽基，别让窗口再滑走一次 |

### 8.3 三个立刻可做的事

1. **把 46.7% 的宽基当"中位数"对待**，不再是"beta 引擎"——它不是你参与结构性牛市的工具
2. **给主线腿（有色/稀土/半导体/创新药）补挂止损**：-8% 或破 MA20，二选一
3. **把确定端补厚**：黄金从 2% 向 5% 走，但**用降仓后的现金，不动用现有权益**

## 九、【补充】开仓前检查清单（10 问）

任何一笔"结构性"买入之前，逐条打勾，**缺 3 条以上不许开仓**：

| # | 问题 | 判据 |
|:--:|---|---|
| 1 | 它属于**已形成趋势**的主线，还是我猜的"下一条主线"？ | 看该板块是否在 MA20 上方且近 20 日跑赢宽基 |
| 2 | 这条主线的**需求是慢变量**，还是一次性政策刺激？ | 卡片第二节第 3 条 |
| 3 | 行业**集中度**在提升吗？龙头份额有没有继续扩大？ | 有数据/财报支撑 |
| 4 | 它有**稳定自由现金流**吗？还是靠融资续命？ | 经营现金流/净利润 > 0.8 |
| 5 | 我现在买它，是因为"格局好"，还是因为"它涨了"？ | 诚实回答 |
| 6 | 我的止损价是多少？（价格止损 or 逻辑止损） | **必须写下来** |
| 7 | 这一笔占我总资产多少？超过 10% 吗？ | ≤10% |
| 8 | 如果它明天跌 8%，我按什么动作？ | 预案必须具体 |
| 9 | 它是"主线底仓"还是"博弈仓"？两者纪律不同 | 明确归类 |
| 10 | 我买它，是不是在**替一个已经涨高的板块找补涨替代品**？ | 若是 → 停手 |

## 十、金句小结

> **结构性牛市，赚的不是估值修复的钱，而是「集中度提升 + 稀缺性溢价」的钱。**
>
> **存量时代，强者行情，最忌讳「弃强择弱，静候补涨」。**
