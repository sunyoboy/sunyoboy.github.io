# 阅读书单 v2：用「可繁殖性」重筛

> **判据来源**：李笑来《1 小时建立终生受用的阅读操作系统》的选书原则 —— 非虚构优先 · 重点领域 心理学 / 经济学 / 脑科学 / 策略学 · **选能"繁殖知识"的方法论书籍**
> **与 v1 的关系**：新建而非合并，四条理由见下
> **建立**：2026-10-14

---

## 为什么新建 v2，而不改 v1

| 理由 | 说明 |
|------|------|
| **1. 筛选起点不同** | v1（[完善操作系统的推荐书单](./reading-list-recommendations)）从**你的知识库缺口**出发，回答"我缺什么 → 读什么"；v2 从**一个外部选书原则**出发，回答"这个原则怎么用、哪些书通不过"。合并会把两套逻辑搅在一起 |
| **2. 语气冲突** | v2 对 v1 的 14 本做了**逐本回测**，其中 1 本判定"不通过"、1 本"部分通过"。原地改会让 v1 的**推荐语气**和 v2 的**判定语气**打起来 |
| **3. 两套排序都要留** | v1 的 🔴🟡 是按**你的现实痛点**排的（行为层卡点、认知偏差）；v2 的排序是按**判据分数**排的。两个维度不互相替代 |
| **4. 不破坏既有引用** | v1 已被 `catalog.md` 与其他文档引用。原地重写会让既有链接指向一个内容已变的文档 |

**一句话**：v1 回答「我该读什么」，v2 回答「**凭什么说它值得读**」。v2 不取代 v1 —— **v2 是 v1 的验收标准**。

---

## 一、把原则变成可执行判据

原文只给了「非虚构 + 4 领域 + 能繁殖知识」，太粗，无法执行。补四条判据：

| 判据 | 问题 | 淘汰谁 |
|------|------|--------|
| **A · 可繁殖性** | 读完能拿走**几个可迁移到别的场景的工具**？拿走 0 个 → 剔除 | 纯叙事、纯结论的书 |
| **B · 给推导还是给结论** | 只给结论＝宣称；给推导 + 反例 + 边界＝方法论 | 金句合集、成功学 |
| **C · 作者有一手产出吗** | 是研究者 / 实战者，还是二手转述者 | 攒稿书、"某某解读" |
| **D · 5 年后还成立吗** | 工具类不怕旧，新闻类半年就废 | 时评、榜单类 |

> **判据 A 是核心**：一本书的价值 = 它往你脑子里装了**几个以后能反复调用的工具**。这就是"繁殖知识"的可操作定义。

## 三、按 4 个领域看真实缺口

| 领域 | 你已有 | 缺口 |
|------|--------|:----:|
| **心理学** | 思考快与慢、噪声、心流、反脆弱、刻意练习、掌控习惯（6 本） | 🟢 **已饱和** —— 再补就是重复 |
| **经济学** | 《聪明的投资者》《博格》《周期》《曹名长》属**投资应用**，不是经济学基础 | 🔴 **最大缺口** |
| **脑科学** | **零** | 🔴 **第二大缺口** |
| **策略学** | 穷查理宝典、系统之美、原则（偏"人生策略"） | 🟡 缺**经典策略 / 博弈论** |

> ⚠️ 关键区分：投资类书是**应用层**，不等于经济学。缺的是**底层机制**那一层。

## 四、补缺口的 8 本（每本都通过 A / B / C / D）

### 🔴 经济学（3 本）

| 书 | 作者 | 可拿走的工具 |
|----|------|------------|
| **《一课经济学》** | 黑兹利特 | **"看得见的与看不见的"** —— 一个用一辈子的工具；破窗谬误。极薄，两晚读完 |
| **《魔鬼经济学》** | 列维特 | **激励如何扭曲行为**；相关性 ≠ 因果 |

### 🔴 脑科学（3 本）—— 这组直接挑战原文

| 书 | 作者 | 可拿走的工具 |
|----|------|------------|
| **《认知天性》** | 布朗 / 罗迪格 | **检索练习、间隔、交错** —— 学习科学三大件 |
| **《为什么学生不喜欢上学》** | 威林厄姆 | 认知科学 9 条原理；**"记忆是思考的残留物"**；戳破"学习风格"迷思 |
| **《我们为什么要睡觉》** | 沃克 | 睡眠与记忆巩固、决策质量 —— 给"能量分区"提供生理依据 |

### 🟡 策略学（2 本）

| 书 | 作者 | 可拿走的工具 |
|----|------|------------|
| **《策略思维》** | 迪克西特 & 奈尔伯夫 | 博弈论 10 个工具：承诺、威胁、可信度、边缘政策、拍卖设计、投票悖论 |

## 五、⚠️ 与「阅读操作系统」的冲突（本文最重要的一节）

李笑来的系统是 **输入 → 处理 → 输出** 三段闭环。

**它没有第四段：存储与检索。**

| 李笑来的主张 | 学习科学的反驳 |
|------------|--------------|
| "精读至上""只字不差" | 反复重读会产生**流畅感错觉** —— 感觉懂了，实际没记住。「读懂」和「记得」是两件事 |
| "阅读只有一种：精读" | 检索练习（合上书回忆）、间隔、交错，效果**远高于**重读。精读是**输入策略**，不是**保持策略** |
| "阅读速度 ≠ 理解速度，慢即是快" | 慢读提升**理解**，但对**长期保持**几乎无帮助 —— 保持靠的是**主动提取的次数**，不是阅读的遍数 |
| "最好的学是教" | ✅ 这条与学习科学一致（生成效应）—— 是全篇最经得起检验的一句 |

**所以**：那套系统擅长**处理**，短板在**保持**。缺的那块正好由脑科学补 —— 这正是把《认知天性》《为什么学生不喜欢上学》排在最优先的原因。

## 六、执行：读多少 / 什么时候停

原文没答的问题，这里给规则。

### 规则 1：一次只精读 1 本

曾国藩「一书未尽，不读新书」—— 这条原文对，且与 v1 一致。

### 规则 2：候选池分三级，不许并列

```
🔴 现在读（只 1 本）
   《认知天性》—— 先修好"保持"环节，之后读什么都更划算

🟠 排队（3 本）
   《一课经济学》 → 《策略思维》 → 《好战略坏战略》

🟡 慢读池（不限时）
   《穷查理宝典》《系统之美》《原则》《为什么学生不喜欢上学》
```

### 规则 3：停止规则（v1 缺的）

每本书读完先问：

> **"我能说出哪三个以后会反复用的工具？"**

说不出三个 → 标记为**闲书**，不写笔记、不进知识库。这条直接执行判据 A。
