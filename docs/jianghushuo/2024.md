## 12-14 · 创业的方法

**摘要**

1. 创业从自己和身边人的真实困难出发。
2. 先解决自己的问题，再看别人是否需要。
3. 判断想法看需求真实、有价值、量力而行。
4. 多接触各行各业的人，扩大遇到机会的面。
5. 落地分明确、制定、执行三个阶段推进。

**核心观点**

1. 从自己正在遇到的麻烦里挑题目，先吃自己的狗粮。
2. 用需求真实、社会与商业价值、自身能力三条筛项目。
3. 主动去认识不同行业的人，扩大自己的幸运表面积。
4. 选定方向后力发一孔，把精力压在一个细分点上。
5. 先小规模试验跑通，再稳步扩张规模。

创业的方法 创业的第一步可以从身边的实际问题出发。找到你或周围人遇到的具体困难，然后看看这个问题是否普遍存在。 
举个例子：我(丹姐)在怀孕期间找不到合适的幼儿园，发现市面上现有的选择都达不到标准，所以我直接开办了一家。 
再比如，猫王的曾大师。他买了很多品牌的收音机都不满意，最后决定自己做一个。 
这就是最基本的创业逻辑：先解决自己的问题，再看别人是否需要这个解决方案。这种方式能确保产品真实可用，我们管这叫"吃自己的狗粮"。 
要怎么判断一个创业想法靠谱不靠谱？我总结了三点： 
第一，市场需求要真实。你遇到的问题，是不是很多人都会遇到？这很关键。 
第二，要有实际价值。拿开幼儿园来说，一方面要对社会有帮助，能推动教育进步；另一方面要有商业价值，比如当时民办园供不应求就是个好机会。 
第三，要量力而行。你得清楚地知道自己能做什么，不能做什么。 
多出去走走，认识各行各业的人，机会才会多。因为你的幸运表面积增大了么。 
机会越多，成功的可能性就越大。 
发现好项目后（要从高度、深度、广度、前瞻度、多个角度来分析），就该定计划了。 
具体可以这样做：洞察、找魂、聚焦和协同。 
要搞清楚市场现状和痛点；理解问题的根本，这就是马斯克说的从本质出发；知道自己的优势在哪。选准一个方向，把有限的精力用在刀刃上，力发一孔；同时要善于合作，整合资源把事情做好。 
简单来说可分为三步：明、定、行 
(明)确阶段：深入了解市场真实需求，评估社会价值与经济价值。（需求、价值、人三角形） 
制(定)阶段：把握市场机遇，明确核心竞争力，聚焦细分领域，整合优质资源（洞察、找魂、聚焦和协同）。 
执(行)阶段：保持开放学习心态，知行合一；从小规模试验起步，稳步扩张规模，在解决社会问题的过程中实现商业价值。

## 12-13 · 我做自媒体的秘诀：

**摘要**

1. 每天只给自己十分钟做视频。
2. 时间被压缩后只能抓最重要的部分。
3. 没有准备时间，内容反而更真实。
4. 把目标降到极小，才更容易天天坚持。

**核心观点**

1. 给创作设一个硬上限，比如十分钟，逼自己抓重点。
2. 选题时先问这件事的第一性原理是什么，再动笔。
3. 把每天任务降到能轻松完成的最小剂量，先保住连续性。
4. 多发几条再去挑好的，不要憋一条追求完美。

我做自媒体的秘诀： 每天要求自己只花10分钟做视频。这样：
1、就要求你必须把关注点放在最重要的事，而不是那些细枝末节上。而人们关注你并不是因为那些细枝末节：第一性原理。
2、因为没有时间“准备”，所以足够真实。真实是必杀技。没人喜欢塑料花。
3、每天做100个俯卧撑很难坚持下来。每天1个俯卧撑就容易多了。这样反而能够更好的积累。无论是知识还是技能。你的知识、技能积累的越高，你越驾轻就熟。反而越来越简单。
4、概率。1天拍3条视频的概率高？还是3条拍1条视频的概率高？这是显而易见的。有疑问，请参见第1、2、3条。

**摘要**

1. 赚钱多少和努力程度关系不大。
2. 选有杠杆、能复利的事，时间越久收益越大。
3. 砍掉杂事，把资源集中在最重要的事上。
4. 先把一件小事做完整，再谈做大事。

**核心观点**

1. 挑一件做得越久收益越大的事，而不是按小时换钱。
2. 开工前先砍掉可做可不做的事，把精力留给主线。
3. 把一件小事做到完整闭环，再复制放大。

学会偷懒 赚钱这个事和工作的努力程度没有太大关系。你要学会巧干。用更少的时间和精力取得更多的收益。
1、做有杠杆且复利的事。做的时间越长获得的收益越大。而不是那种花一分辛苦得一份薪水的事。
2、断舍离。为最重要的事做好准备。集中优势兵力干大事。
3、从小事做起。把它做好做完整。不是一上来就做什么大事。而是认真把一件小事做成一件大事。流水不争先，争的是滔滔不绝。

## 09-21 · 提高收入的方法和途径

**摘要**

1. 收入来自自己的劳动技能，不是老板给的。
2. 第二层是用业余时间接零工，把技能卖多次。
3. 副业的意义在把技能具体化，而非挣多少钱。
4. 第三层是把知识和技能做成产品。
5. 产品化之后，收入不再被时间束缚。

**核心观点**

1. 先承认收入由自己的技能决定，别再归因于老板。
2. 用业余时间接一单零工，把能力变成可出售的技能。
3. 把一次交付做成能卖给多个用户的形态。
4. 把重复劳动做成软件、工具或一本书。
5. 收入卡住时，先问自己在卖时间还是在卖产品。

提高收入的方法和途径 简单赚点小钱的三个层次：
1、打工。大多数人的思维是严重受限的。他们很多人仍然认为自己的收入愿意老板或者领导。但实际上，你的收入来自于你的劳动技能所得。
如果你能理解这个逻辑，那你就可以试着进入下一个关卡。
2、副业。利用业余时间固定的接一些“零工”。这些零工很可能就是当下最需要的技能。挣多少钱倒不是很重要。重要的是你的技能具体化了，你可以把技能出售给多个用户。
这是1 x 1和1xn 的关系。
3、产品构建。把你的知识、技能产品化。把你的时间用在构建产品上，比如用软件自己化解决方案；直接做个“工具”；或者这本书。这些都是产品化的案例。这时你就会脱离用时间赚钱的束缚。
一旦进入这个阶段，你自己就知道后面该怎么做了。

## 09-07 · 聪明的做事

**摘要**

1. 借科技变革的势，等于搭上电梯。
2. 新技术刚出现时最粗糙，也最好切入。
3. 做事先从最简单处开始，不求一步完美。
4. 浪潮来之前先下水，提前熟悉水性。

**核心观点**

1. 新技术一出现就先用起来，别等它成熟。
2. 动手前先问有没有更简单的方案能达到目标。
3. 用替代品先搭一个粗糙模型，跑通再进化。
4. 在新趋势到来前，先做一个小项目试水。

聪明的做事 1、要学会借势。尤其是科技带来的变革。新技术刚刚推出时，一定是非常粗糙的。你可以利用这个机会上电梯。事半功倍。
2、想做事，一开始不要想着太完美。从最简单处开始，看看达到目标有没有更简单的解决方案，然后再一步一步进化。学习同样如此。
3、在新的浪潮来临之前，你最好已经在水里了，提前熟悉水性。很多事没有你想的那么复杂。一件事做好很难，完成很容易。你完全可以用一些替代品提前把一个粗糙的模型搭起来。我之前说过，一个新技术流行起来之前都是极粗糙的。这是你的机会。
