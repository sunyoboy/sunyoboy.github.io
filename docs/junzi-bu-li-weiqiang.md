# 君子不立危墙之下

> 出自《孟子·离娄上》· 投资决策的底层哲学根基

---

## 一、出处

> 孟子曰："莫非命也，顺受其正；是故**知命者不立乎岩墙之下**。尽其道而死者，正命也；桎梏死者，非正命也。"

原文为「不立乎岩墙之下」，后世通俗化为「君子不立危墙之下」。

**岩墙**：倾斜、快要倒塌的危墙。

---

## 二、字面释义

有德行、有智慧的人，不会站在快要倾倒的危墙底下。

---

## 三、三层深层含义

### 1. 避险自保：主动远离显而易见的风险

危墙代表**看得见的灾祸、隐患、是非漩涡**。

聪明人不等灾难砸到头上，提前避开危险环境、危险人和危险事，不心存侥幸赌运气。

> 例：远离品行不端之人、不参与投机冒险、不踏入是非纷争。

### 2. 明辨祸福：分清「正命」与「枉死」

孟子核心本意：生死有天命，但人不能主动把自己置于死地。

| 概念 | 含义 | 例 |
|------|------|------|
| **正命** | 坚守道义、尽本分而坦然赴死 | 舍生取义 |
| **非正命** | 明知有危险还主动凑上去，白白招来横祸 | 赌博式抄底、无视止损 |

> 人不必无谓牺牲，爱惜自身也是修身的一部分。

### 3. 修身智慧：事前预判，防患未然

真正的君子不是胆小，而是**有远见、懂权衡**。

懂得观察环境、预判隐患，凡事留退路，不置身无法掌控的险境，是成熟的处世思维。

---

## 四、延伸处世应用

| 领域 | 应用 |
|------|------|
| **职场** | 不掺和派系内斗、远离违规灰色业务，不替他人背锅 |
| **人际** | 远离消耗自己、惹是生非的人，不卷入他人恩怨 |
| **投资/抉择** | 避开明显有漏洞、高风险的选择，不贪短期利益忽略隐患 |
| **行事底线** | 凡一眼就能看见风险的事，绝不心存侥幸 |

---

## 五、投资场景映射

> 本节将古典智慧映射到 A 股交易的具体场景。

### 🧱 什么是 A 股市场的「危墙」

| 危墙 | 识别信号 | 对应纪律 |
|------|------|------|
| **重大事件前夕** | FOMC/PCE/政治局会议 | [仓位纪律](position-discipline.md)：事件前 2 天减仓至 ≤40% |
| **趋势破坏** | MA5 死叉 MA20 + 中期空头 + 偏离扩大 | [MA5 偏离度纪律](ma5-deviation-discipline.md)：清仓或减至观察仓 |
| **杠杆踩踏** | 连续暴跌 + 缩量 + 抄底盘被反复惩罚 | 「大跌敢买」五条件不满足 → 不抄底 |
| **止损被触发** | 价格跌破预设止损线 | 不找理由，市价执行 |
| **流动性枯竭** | 成交额持续萎缩 + 波动放大 | 减少交易频率，不挂大单 |
| **月末/节前** | 流动性季节性收紧 | 不开新仓 |

### 🧭 「不立危墙」的五个交易动作

| # | 动作 | 对应原文逻辑 |
|:--:|------|------|
| 1 | **FOMC/PCE 前减仓** | 看见危墙倾斜 → 先走开，不等它倒 |
| 2 | **止损触发立即执行** | 墙已经开始掉砖 → 不等被砸再跑 |
| 3 | **不接飞刀（不抄底暴跌）** | 墙正在倒 → 不凑过去看热闹 |
| 4 | **设条件单而非手动盯盘** | 不站在墙下 = 不把身体暴露在风险中 |
| 5 | **现金在手等确定性** | 墙倒完了、扬尘落定 → 再走过去 |

### ⚡ 反面案例（立危墙之下）

| 行为 | 为什么是立危墙 | 历史教训 |
|------|------|------|
| FOMC 前不减仓 | 重大不确定性 = 岩墙倾斜 | 7/28 不减仓 → 7/30 科创 -5.38% |
| 「跌这么多了总该反弹了」 | 心存侥幸 = 赌墙不会倒 | 7/27 抄底 → 7/28 被埋 → 7/29 抄底 → 7/30 再被埋 |
| 止损到了不执行 | 找理由不执行 = 站在墙下不走 | 卫星ETF 1.35 → 1.002（-25.8%） |
| 追涨杀跌 FOMO | 情绪驱动 = 不看墙就往里冲 | 7/27 追涨创业板 +1.55% → 次日 -7.35% |

## 六、配套互补名句对照

| 名句 | 维度 | 与「不立危墙」的关系 |
|------|:--:|------|
| **君子不立危墙之下** | 事前避险 | 🧱 看见危险 → 远离 |
| **防祸于先而不致于后伤情** | 提前防范 | 🔮 不等灾祸发生再补救 |
| **知进退，明得失** | 懂得抽身 | 🚪 已经站在墙下了 → 及时退出 |
| **危邦不入，乱邦不居** | 远离动荡 | 🌍 孔子同逻辑：不进入危险环境 |

---

## 七、辩证提醒

> ⚠️ 这句话不是教人懦弱逃避责任。

| 该避的 | 不该避的 |
|------|------|
| 无意义、可避免的无端灾祸 | 道义、责任所在（守护家人、坚守公理） |
| 赌运气式的投机 | 计算过风险收益比的合理承担 |
| 明知有坑还往里跳 | 为保护更重要的事物而面对的困难 |

> **只规避「非正命」——明知有危险还主动凑上去的白白横祸。不逃避「正命」——该担当的责任。**
