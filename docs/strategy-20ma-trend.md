### 2.2 开仓入场条件（**全部同时满足**，盘后选股 → 次日开盘开仓）

```
1. MA20 今日 > MA20 昨日        （20 日均线拐头向上）
2. Close > MA20                 （收盘价站上 20 日均线）
3. 近 20 日波动率 > 2%           （过滤死水横盘震荡）
4. 该标的当前无持仓              （不重复开仓）
```

### 2.3 出场规则（止损 / 趋势离场，**谁先触发谁执行**）

#### 止损规则

```
单笔最大亏损 = 总资金 × 1% = 3,000 元
止损价       = 入场价 × (1 − 3%)
持仓股数     = 3,000 ÷ (入场价 − 止损价)
收盘价跌破止损价 → 次日开盘全部清仓该标的
```

#### 趋势离场规则（优先，不设固定止盈）

```
Close < MA20 → 次日开盘清仓
```

> 趋势不破就持有 —— **截断亏损，让利润奔跑**。

## 八、Python 回测代码

### 8.1 信号逻辑（伪代码）

```python
data['ma20']  = data['close'].rolling(window=20).mean()
data['vol20'] = data['close'].pct_change().rolling(20).std()

# 入场
cond1 = data['ma20'] > data['ma20'].shift(1)
cond2 = data['close'] > data['ma20']
cond3 = data['vol20'] > 0.02
enter_signal = cond1 & cond2 & cond3

# 出场
stop_loss_price = entry_price * 0.97
exit_stop  = data['close'] < stop_loss_price
exit_trend = data['close'] < data['ma20']
exit_signal = exit_stop | exit_trend
```

### 8.2 VectorBT 批量回测骨架

```python
import vectorbt as vbt

symbols = [
    "510300", "588000", "159915", "002149", "000657", "002050",
    "002475", "600111", "000651", "159992", "510500", "511090",
    "159985", "512400", "518800",
]

price = vbt.YFData.download(symbols, start='2016-01-01', end='2026-06-30').get('Close')

ma20  = vbt.MA.run(price, window=20)
vol20 = price.pct_change().rolling(20).std()

cond1 = ma20.ma > ma20.ma.shift(1)
cond2 = price > ma20.ma
cond3 = vol20 > 0.02
entries = cond1 & cond2 & cond3

sl_price   = price * 0.97
exit_sl    = price < sl_price
exit_trend = price < ma20.ma
exits = exit_sl | exit_trend

pf = vbt.Portfolio.from_signals(
    price, entries, exits,
    fees=0.00025,
    sl_stop=0.03,
    freq='D',
)
pf.stats()
```

> **批量回测时必须分开 ETF 和个股，印花税、滑点分开设置，否则回测收益虚高。**

## 九、⚠️ 三处待裁决（必须先定，否则策略无法执行）

### 待裁决 1 🔴 **「单笔风险 1%」与「单标的 10%」互相矛盾 —— 1% 永远达不到**

**推导**（纯数学，与入场价无关）：

```
止损价 = 入场价 × 0.97        → 每股亏损 = 入场价 × 3%
持仓股数 = 3,000 ÷ (入场价 × 3%)
持仓金额 = 股数 × 入场价 = 3,000 ÷ 3% = 100,000 元   ← 恒为 10 万
```

**结论**：按 1% 风险反算，**每笔仓位恒定 100,000 元 = 总资金的 33.3%**，**必然撞上「单标的 ≤10%（30,000 元）」的上限**。

原文自己也写了"如果算出资金超过 3W，按 3W 上限开仓" —— 那么：

```
实际单笔风险 = 30,000 × 3% = 900 元 = 总资金的 0.3%
              （不是文档写的 1%）
```

**三个选项（选一个，写进文档）**：

| 选项 | 做法 | 后果 |
|---|---|---|
| **A（推荐）** | 以 **10% 单标的上限为准**，把文档里的"单笔风险 1%"改成 **0.3%** | 单笔风险更小；5 只全止损 = **1.5%** 账户回撤，远低于 5% 红线 |
| B | 保持 1% 风险，把单标的上限放宽到 **33%** | 与"分散"目标冲突，5 只即满仓 |
| C | 保持 1% 风险 + 10% 上限，把**止损幅度放宽到 10%** | 与"趋势离场 Close<MA20"功能重叠，且单笔亏损体感大 |

> **A 的连带效果**：单笔风险 0.3% × 5 只 = 全部止损也只有 **1.5%** 回撤。
> 因此 **5% 硬红线需要约 3.3 轮"5 只全部止损"**才会触及 —— 这个红线**不容易被连续止损触发**，主要风险来自**同时性的跳空/滑点**（第四节情景 2）。
